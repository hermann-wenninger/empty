# Repository Overview

This repository contains various experimental projects and applications.

## Projects

### 🤖 LLM Agent Chain Builder
A no-code React application for creating and connecting LLM agent workflows, similar to LangChain. Build visual agent chains by connecting different node types (Input, LLM Agent, Tool, Decision, Output) without writing code.

**Location:** `llm-agent-builder/`

**Features:**
- Visual workflow builder with drag-and-drop
- Multiple LLM model support (GPT-4, Claude, Llama, Gemini)
- Node-based architecture for creating agent chains
- Beautiful modern UI with animations

[See the LLM Agent Builder README](llm-agent-builder/README.md) for more details.
